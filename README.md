# 📊 AMBRE Floating Solar 42.5 MWp - Interactive S-Curve & Executive Timeline Dashboard

Interactive Construction S-Curve & Executive Schedule Dashboard for **AMBRE Floating Solar Amata City Chonburi 42.5 MWp Project**.

## 🌟 Key Features
- **Interactive S-Curve Charts**: Plan (Rev.A) vs Forecast (Rev.0A) vs Actual Progress across all disciplines.
- **Progress Summary Table**: Discipline breakdown for Permit, Engineering, Procurement, Construction, Commissioning & Handover.
- **Executive Master Schedule & Timeline**: Key Milestones (LNTP, KOM, 22kV Tie-in, M/C, 1st Syn, COD 31 July 2027).
- **Export Capabilities**: Download PNG Charts, Print Executive PDF, and Export CSV.

## 🚀 How to View
Open `index.html` in any modern web browser or visit the GitHub Pages link.
